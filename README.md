# amr-m-abdelgawad.github.io

This user site keeps the previous documentation address working.

GitHub Pages publishes [Devctl](https://github.com/amr-m-abdelgawad/Devctl) at `https://amr-m-abdelgawad.github.io/Devctl/`. That path is case-sensitive, so `https://amr-m-abdelgawad.github.io/devctl/` is not the project site. `404.html` redirects that older casing, and any other casing of the name, to `/Devctl/` while keeping the rest of the path.
